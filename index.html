01تاريخ الحاسوب

قبل ما نبدأ نتعلم البرمجة، من المفيد إننا نعرف إزاي الحاسوب اتطور عبر التاريخ، لأن فهم هذا التطور يساعدنا في فهم سبب عمل الأجهزة والبرامج بالشكل اللي بنشوفه بيه النهاردة.

1. بدايات الحوسبة (قبل الكهرباء)

العداد (الأباكوس) — من آلاف السنين. يُعتبر أول أداة استخدمها الإنسان لإجراء العمليات الحسابية: إطار خشبي بخرزات يُستخدم للعد والجمع والطرح.

آلة باسكال الحاسبة — 1642. صمم العالم الفرنسي بليز باسكال أول آلة ميكانيكية قادرة على الجمع والطرح التلقائي باستخدام التروس.

المحرك التحليلي — 1837. اقترح العالم البريطاني تشارلز باباج تصميم آلة ميكانيكية معقدة عُرفت بـ"المحرك التحليلي"، احتوت على وحدة حسابية وذاكرة ووحدة إدخال/إخراج — وهو ما يشبه فكرة الحاسوب الحديث. لهذا، يُلقَّب باباج بـ"أبو الحاسوب".

أول مبرمجة في التاريخ — آدا لوفلايس. كتبت مجموعة من التعليمات لتشغيل المحرك التحليلي الخاص بباباج، وبذلك تُعد أول شخص في التاريخ يكتب "برنامج حاسوبي".

2. أجيال الحاسوب الخمسة

الجيلالفترة الزمنيةأهم الخصائص
الجيل الأول1940 – 1956استخدم الصمامات المفرغة؛ أجهزة ضخمة كانت تملأ غرفة كاملة وتستهلك طاقة هائلة (مثل جهاز ENIAC).
الجيل الثاني1956 – 1963حلت الترانزستورات محل الصمامات المفرغة، مما جعل الأجهزة أصغر وأسرع وأكثر كفاءة في استهلاك الطاقة.
الجيل الثالث1964 – 1971اختراع الدوائر المتكاملة، التي جمعت آلاف الترانزستورات في شريحة واحدة صغيرة.
الجيل الرابع1971 – حتى الآنظهور المعالج الدقيق، الذي يضع وحدة معالجة كاملة على شريحة واحدة — وهو أساس أجهزة الحاسوب الشخصية الحديثة.
الجيل الخامسالحاضر والمستقبلحواسيب مبنية على الذكاء الاصطناعي وتعلم الآلة والمعالجة المتوازية فائقة السرعة.
💡 أول حاسوب شخصي منتشر تجاريًا كان جهاز Altair 8800 عام 1975؛ وبعده ظهرت شركات مثل Apple وIBM لتطرح أجهزة الحاسوب الشخصية اللي بنعرفها النهاردة.

02مكونات الحاسوب بالتفصيل

من ناحية المكونات، يُقسَّم الحاسوب إلى جزأين رئيسيين: العتاد (Hardware) وهو الأجزاء المادية الملموسة، والبرمجيات (Software) وهي مجموعة التعليمات التي تُشغِّل هذا العتاد. هنا هنركز على مكونات العتاد الأساسية.

1. المعالج المركزي (CPU)

يُعتبر "عقل" الحاسوب، وهو المسؤول عن تنفيذ جميع التعليمات والعمليات الحسابية والمنطقية. ويتكون من:

  • وحدة الحساب والمنطق (ALU): تنفذ العمليات الحسابية (جمع، طرح...) والعمليات المنطقية (مقارنة، شروط...).
  • وحدة التحكم (CU): تدير وتنسق عمل جميع أجزاء الحاسوب وتوجه تدفق البيانات بين الوحدات.
  • السجلات (Registers): ذاكرة صغيرة جدًا وفائقة السرعة داخل المعالج تخزن البيانات التي يعمل عليها المعالج مباشرة.
  • الذاكرة المخبأة (Cache): ذاكرة سريعة قريبة من المعالج تُستخدم لتخزين البيانات الأكثر استخدامًا لتسريع الأداء.

2. الذاكرة

  • RAM: ذاكرة مؤقتة سريعة يستخدمها الحاسوب لتخزين البيانات والبرامج أثناء التشغيل فقط؛ تُفقد محتوياتها عند إغلاق الجهاز (ذاكرة متطايرة).
  • ROM: ذاكرة دائمة تحتفظ بالبيانات حتى بعد إغلاق الجهاز، وعادة ما تحتوي على تعليمات الإقلاع الأساسية للجهاز.

3. وحدات التخزين

  • HDD: وحدة تخزين ميكانيكية تستخدم أقراصًا مغناطيسية دوارة؛ سعة كبيرة وسعر منخفض نسبيًا.
  • SSD: وحدة تخزين إلكترونية بدون أجزاء متحركة، أسرع بكثير من الـ HDD.
  • وحدات التخزين الخارجية: مثل الفلاشات وكروت الذاكرة.

4. اللوحة الأم (Motherboard)

اللوحة الرئيسية التي تُركَّب وتُوصَّل عليها جميع مكونات الحاسوب؛ تحتوي على منافذ توصيل للمعالج والذاكرة وكروت التوسعة ومزود الطاقة وغيرها.

5. وحدات الإدخال

هي الأجهزة التي تُدخل البيانات إلى الحاسوب، مثل: لوحة المفاتيح، الماوس، الماسح الضوئي، الميكروفون، والكاميرا.

6. وحدات الإخراج

هي الأجهزة التي يعرض من خلالها الحاسوب النتائج للمستخدم، مثل: الشاشة، الطابعة، والسماعات.

7. مكونات مهمة أخرى

  • كارت الشاشة (GPU): معالج متخصص في التعامل مع الرسوميات والصور والفيديو.
  • مزود الطاقة (PSU): يحوّل الكهرباء القادمة من المصدر إلى الجهد المناسب لتشغيل جميع مكونات الجهاز.
  • المنافذ (Ports): مثل منافذ USB وHDMI التي تربط الحاسوب بالأجهزة الخارجية.

03الدرس الأول في أساسيات C++

1. ما هي لغة C++؟

لغة C++ هي لغة برمجة قوية ومتعددة الأغراض، طورها عالم الحاسوب الدنماركي بيارن ستروستروب في مختبرات Bell Labs في أوائل الثمانينيات كامتداد للغة C، مع إضافة مفاهيم البرمجة الكائنية. تُستخدم اليوم في بناء أنظمة التشغيل والألعاب والبرامج عالية الأداء والأنظمة المدمجة.

ليه نبدأ بـ C++؟ لأنها تعلمك أساسيات البرمجة بعمق (إزاي تعمل إدارة الذاكرة، وإزاي الحاسوب بيشتغل من الداخل)، وتُعتبر أساسًا ممتازًا لتعلم لغات تانية لاحقًا زي Java وC# وPython.

2. إيه اللي محتاجه عشان تبدأ؟

  • محرر أكواد أو بيئة تطوير (IDE): زي Code::Blocks أو Dev-C++ أو Visual Studio Code.
  • مترجم (Compiler): برنامج يحوّل الكود اللي بتكتبه إلى لغة يفهمها الحاسوب، زي GCC أو MSVC.

3. البنية الأساسية لأي برنامج C++

عادةً يتكون أي برنامج C++ من العناصر التالية:

  • مكتبات تُستدعى في بداية الملف باستخدام #include
  • دالة main()، وهي نقطة بداية التنفيذ لأي برنامج
  • مجموعة من الأوامر (statements) داخل أقواس { }
  • الجملة return 0; في نهاية الدالة main تشير إلى انتهاء البرنامج بنجاح

4. أول برنامج لك: Hello World

البرنامج التالي هو أبسط برنامج ممكن تكتبه في C++، وهو بيطبع رسالة ترحيب على الشاشة:

// My first C++ program
#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}

5. شرح سطر بسطر

السطرالشرح
#include <iostream>تستدعي مكتبة الإدخال/الإخراج، ولازمة عشان نستخدم أوامر الطباعة زي cout.
using namespace std;تسمح باستخدام عناصر المكتبة القياسية (زي cout) مباشرة، من غير كتابة std:: قبلها كل مرة.
int main()الدالة الرئيسية اللي بيبدأ منها تنفيذ أي برنامج C++؛ كلمة int تعني إنها بترجع قيمة رقمية.
{ }الأقواس المعقوفة تحدد بداية ونهاية جسم الدالة (مجموعة الأوامر المراد تنفيذها).
cout << "Hello, World!" << endl;تطبع النص الموجود بين علامتي التنصيص على الشاشة، ثم تنتقل لسطر جديد عن طريق endl.
return 0;ترجع القيمة صفر لنظام التشغيل لتوضيح إن البرنامج انتهى بنجاح من غير أخطاء.

6. قواعد أساسية لازم تفتكرها

  • كل جملة (statement) في C++ لازم تنتهي بفاصلة منقوطة ;
  • لغة C++ حساسة لحالة الأحرف، يعني Main مختلفة عن main
  • التعليقات (Comments) تُستخدم لشرح الكود ومش بتتنفذ: تعليق سطر واحد بـ //، وتعليق متعدد الأسطر بين /* … */
  • الأقواس المعقوفة { } بتُستخدم دايمًا لتحديد بداية ونهاية كتلة الأوامر
✏ تمرين: جرب تعدّل على البرنامج السابق عشان يطبع اسمك بدل "Hello, World!"، وبعدين ضيف سطر تاني يطبع تحية إضافية باستخدام cout تاني.

04المتغيرات وأنواع البيانات في C++

1. إيه هو المتغير؟

المتغير هو مساحة مسماة في ذاكرة الحاسوب (RAM) تُستخدم لتخزين قيمة يمكن للبرنامج قراءتها أو تغييرها أثناء التنفيذ. وعشان الحاسوب يستخدم المساحة دي بشكل صحيح، لازم نحدد نوع البيانات اللي هيتم تخزينها فيها، لأن كل نوع محتاج مساحة مختلفة من الذاكرة ويسمح بعمليات مختلفة.

2. إزاي تعرّف متغير

الصيغة العامة لتعريف متغير في C++ هي:

data_type variable_name = initial_value;

مثال عملي:

int age = 20;          // متغير من نوع عدد صحيح
double price = 49.99;  // متغير من نوع عدد عشري
char grade = 'A';      // متغير من نوع حرف واحد
bool isPassed = true;  // متغير من نوع منطقي

ممكن كمان تعرّف متغير من غير ما تديله قيمة ابتدائية، وبعدين تحدد القيمة له لاحقًا في سطر منفصل:

int score;
score = 85;

3. أهم أنواع البيانات الأساسية

النوعيُستخدم لتخزينالحجممثال
intأعداد صحيحة (بدون فاصلة عشرية)4 بايتint age = 20;
floatأعداد عشرية (دقة عادية)4 بايتfloat price = 9.99f;
doubleأعداد عشرية (دقة أعلى)8 بايتdouble pi = 3.14159;
charحرف واحد1 بايتchar grade = 'A';
boolقيمة منطقية: true أو false1 بايتbool isReady = true;
stringنص (مجموعة أحرف)متغيرةstring name = "Ali";

4. الثوابت (Constants)

أحيانًا نحتاج قيمة لازم متتغيرش أبدًا أثناء تنفيذ البرنامج، زي قيمة ثابت رياضي. في الحالة دي، نستخدم الكلمة المفتاحية const قبل نوع البيانات:

const double PI = 3.14159;

أي محاولة لاحقة لتغيير قيمة PI هتؤدي لخطأ في الترجمة (compile error).

5. قواعد تسمية المتغيرات

  • اسم المتغير لازم يبدأ بحرف أو شرطة سفلية _، مش برقم.
  • ممكن يحتوي فقط على حروف وأرقام وشرطات سفلية — من غير مسافات أو رموز خاصة.
  • لغة C++ حساسة لحالة الأحرف، يعني age وAge يُعتبروا متغيرين مختلفين تمامًا.
  • الكلمات المحجوزة في اللغة (زي int أو return) مينفعش تُستخدم كاسم متغير.
  • الأفضل اختيار أسماء واضحة توصف الغرض من المتغير، زي studentAge بدل x.

6. مثال كامل

البرنامج التالي بيعرّف مجموعة متغيرات من أنواع مختلفة وبعدين يطبعها على الشاشة:

#include <iostream>
using namespace std;

int main() {
    string name = "Sarah";
    int age = 22;
    double gpa = 3.75;
    bool isEnrolled = true;

    cout << "Name: " << name << endl;
    cout << "Age: " << age << endl;
    cout << "GPA: " << gpa << endl;
    cout << "Currently enrolled: " << isEnrolled << endl;
    return 0;
}
✏ تمرين: ضيف متغير جديد من نوع char يخزن الحرف الأول من اسمك، وبعدين اطبعه باستخدام cout.
